## Активные

### E-001 · Порядок drop в конце блока
- lesson: 03
- error: неверное предсказание порядка в журнале natural_order
- thought: «сначала в расте умирают старые, а потом новые»
- actually: переменные умирают LIFO: последняя созданная освобождается первой (обратный порядок объявления)
- interval: 3
- due: 2026-10-22

### E-002 · Затенение не освобождает значение
- lesson: 03
- error: неверное предсказание журнала fifo_order с тремя `let _fifo`
- thought: «при повторном let с тем же именем старое значение должно умереть»
- actually: затенение отнимает только имя; старое значение живёт до конца блока и умирает по LIFO вместе с остальными
- interval: 1
- due: 2026-10-19

### E-003 · mut не меняет тип
- lesson: 02
- error: E0308 mismatched types (разминка: `let mut x = "42"; x = x.len();`)
- thought: «с `mut` можно присвоить переменной значение другого типа»
- actually: «`mut` меняет только значение, тип остаётся прежним; сменить тип можно только через новую `let` (shadowing)»
- interval: 1
- due: 2026-10-19

### E-004 · `let _ =` дропает сразу
- lesson: 03
- error: неверное предсказание в predict.rs (`let _ = TempFile {..}` вместо `let _first`)
- thought: «`let _ =` значит, что значение не нужно и не будет существовать, drop не сработает»
- actually: «значение создаётся и сразу дропается на `;`, потому что у него нет владельца; `_first` — обычная переменная, она живёт до конца блока»
- interval: 3
- due: 2026-10-22

### E-005 · Кто и когда вызывает drop
- lesson: 03
- error: пробел, найденный JS-джуном (объяснение по Фейнману)
- thought: «память освобождает разработчик; drop срабатывает там, где значение использовалось в последний раз»
- actually: «компилятор сам вставляет drop на закрывающей `}` области видимости владельца, даже если значение больше не используется»
- interval: 1
- due: 2026-10-20

### E-006 · Что на самом деле запрещает «много & или один &mut»
- lesson: 04
- error: пробел, найденный JS-джуном (объяснение по Фейнману)
- thought: «правило нужно, чтобы функция не посчитала результат по старому значению, пока другая его меняет»
- actually: «прочитать старое до изменения можно; правило запрещает ссылке пережить изменение, иначе она будет смотреть в освобождённую память или в наполовину обновлённое состояние»
- interval: 1
- due: 2026-10-22
